Put the two scan files into the app folder (MUI_Lightning_Group_3/, e.g. next to Narration/):

  LandscapeModel.referenceobject   – trained in Create ML (Object Tracking) from LandscapeScan.usdz
  LandscapeScan.usdz               – already here: the corrected scan (measured size, model space),

Exactly these names. They are bundled automatically. Without them the app falls back to
placing the model by hand (Place the model → Save position).
